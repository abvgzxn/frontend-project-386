# Публичная главная и честная заглушка записи

Главная страница «Календаря звонков» является публичным входом гостя к записи: она объясняет назначение сервиса, показывает нейтральные шаги работы и ведёт на `/book`. До реализации бронирования `/book` остаётся честной заглушкой с понятным статусом и возвратом на `/`, а техническая проверка API не показывается гостю. Это сохраняет реальный пользовательский путь, не имитируя ещё не существующую функциональность.

## Принятые решения

- Главная содержит минимальную шапку, hero с заголовком «Запишитесь на удобный звонок», объяснение назначения, CTA «Записаться на звонок» и видимую подпись «Регистрация не требуется».
- Ниже hero показывается нейтральный блок из шагов «Выберите формат», «Найдите удобное время», «Подтвердите запись».
- Визуальное направление сочетает ясную landing-структуру Calendly с более тёмным и выразительным настроением Cal.com; используется абстрактная графика, а не стоковая фотография.
- Публичный путь включает `/` и `/book`; CTA из шапки и hero ведут на `/book`, а заглушка возвращает на `/`.
- Первая фича обязана работать на mobile и desktop и соблюдать базовую доступность: клавиатурная навигация, видимый focus, достаточный контраст и семантическая структура.

## Последствия

Текущая страница со статусом API заменяется пользовательской главной и больше не показывает технические детали. Порядок выбора длительности, типа встречи и времени не выводится на главной и не считается утверждённым этим ADR.
